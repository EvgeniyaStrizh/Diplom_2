
Базовый URL: `https://stellarburgers.nomoreparties.site/api`
Описание тестируемых эндпоинтов:
  - `/auth/register` - регистрация пользователей
  - `/auth/login` - авторизация пользователей
  - `/auth/user` - обновление данных пользователя
  - `/ingredients` - получение списка ингредиентов
  - `/orders` - создание и получение заказов

Тестовые сценарии
1. Регистрация пользователей:
  - Создание уникального пользователя
  - Попытка создания существующего пользователя
  - Валидация обязательных полей (email, password, name)
2. Авторизация пользователей:
  - Успешная авторизация
  - Авторизация с неверными данными
  - Авторизация несуществующего пользователя
3. Обновление данных пользователя:
  - Обновление с авторизацией
  - Обновление без авторизации
4. Работа с заказами:
  - Создание заказа с авторизацией
  - Создание заказа без авторизации
  - Валидация ингредиентов
  - Получение заказов пользователя
